The v71 and v74 reports showed recent five-swap medians 337ms and 365ms on OnePlus PMS110. v83 N5 1123ms and v84 OnePlus 595ms cannot be treated as a controlled version comparison; v78–82 and v83 OnePlus reports have not been recovered. v74 only offloaded move IPC; v80–83 added serialized foreground/layout/active query calls. This experiment uses precisely the original v83 production ExchangeSession and repository read/publish. Both modes run the same real move IPC on the existing Binder lane, same polls, owner validity and identity proof. Only the destination observation read happens on owner versus worker; both publish on owner, both fail honestly. Two untimed warmup sessions, 30 AB/BA alternating pairs. Measure total, promotion, demotion, query wall, owner read/decode/publication cost, worst individual owner read and count; preserve individual attempts. The owner variant is research only and may block UI: no production changes, no APK delivery. This fixture is one independent remote task round trip plus separate real pixel smoke, not a full two-task workspace exchange or ColorOS frame rate. Do not accept a production patch based on these data alone.
