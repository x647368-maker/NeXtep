## 功能隔离及测试用例

### Lenovo Y700（TB324ZC；真实联想硬件，Root + ColorOS 16 手机 ROM 移植）

- [ ] 竖屏：顶部状态栏与工作台控件没有遮挡，按钮可点击，状态栏可下拉并恢复。
- [ ] 横屏：**顶部横排**是独立选项，不是“左侧=上方/右侧=下方”；一至四个小窗保持正向、大小合理。
- [ ] 横屏：**左侧竖排**真正处于左侧；**右侧竖排**真正处于右侧；主窗位于剩余区域而不留异常大空白。
- [ ] 三种布局循环切换：主窗/小窗内容与触控区域保持同步，未出现黑屏、强制旋转、位置跳变。
- [ ] 移植 ROM 报告非典型屏幕旋转编号、高 DPI 或空状态栏 inset 时不误入手机布局。
- [ ] 侧栏隐藏与白色边缘条恢复、第四个应用添加和主小窗交换均可用。

### OPPO Find N5（展开/折叠分别测试）

- [ ] 展开后顶部横排：小窗预览不会大于主窗；主窗尽量利用空间，但纵向应用不拉伸、不裁切。
- [ ] 左、右侧栏：空闲后真正隐藏并为主窗释放空间；白色小竖条触控能**立即**恢复四个窗口。
- [ ] 在主窗忙于切换任务时，自动隐藏不应被重复任务通知无限延期；拖动小窗时不突然消失。
- [ ] 常用快捷栏可以从实际可用应用/个人固定记录中显示更多项，空位不捏造图标。
- [ ] `+` 仅添加固定常用应用；原“替换主应用”仍在主菜单中可找到；长按可移除、排序，重启后固定状态保持。
- [ ] 折叠屏合起和再次展开后，布局/常用栏状态不串屏、不卡死；检查 N5 **平行视窗由主窗口负责**，不可用备用4结果直接宣称已修。

### 一加 Ace 7 Pro（主力机：优先保护）

- [ ] 原有顶部/左右小窗、切换动画、圆角、原生通知栏手势保持稳定。
- [ ] 现有 5 个自动常用应用的紧凑手机显示规则保持不变；不会误启用 N5 自动放大。
- [ ] 主小窗交换、任务显示、触控、耗电和重复打开工作台均无明显回归。
