# 手动故障测试与报告（内测）

首页「故障测试与报告」→ 「开始测试」→ 离开本页复现问题 → 回来「标记问题发生」（可选）→ 「结束测试并生成报告」→ 「导出报告」，手动选择文件保存位置。不会自动上传酷安或发给开发者。

**低功耗策略：** 未开始时无监控服务或循环；开始后仅记录一个本地时间戳和即时电池/现有 SystemUI 状态；用户点击标记时只保存时间戳；结束再读取一次状态。没有自动截图、屏幕录制、读全量日志、后台采样、定时唤醒或网络请求。最长有效标记窗口 30 分钟，最多 12 个标记。

**报告范围：** App/Android 版本和设备型号、开始和结束电量与温度、工作台是否开启/是否挂起、虚拟小窗数量、现有系统界面进程计数的差值、用户手工文字。SystemUI 未响应则标记不可用；报告不应被描述成崩溃堆栈、全量运行日志或独占模块电量。

**安全：** 文件仅在用户选择保存位置后写入。不自动分享，不含其他应用的包名/消息；用户自由输入的问题描述可能包含敏感信息，应分享前自行检查。应用内部仅使用 private SharedPreferences 保存最新一次摘要；开始新测试会覆盖旧一次记录，不持续保留多份。

**限制：** App 或 SystemUI 在测试时重启，会造成部分数据缺失。计数差异是 SystemUI 进程总量，不能直接证明台前调度单独的耗电。签名迁移、手机/平板窗口适配、安全检查均不在此功能中更改。尚需真机手测。
