# 台前调度｜自动到期故障测试 v0.9.22-dev

## 给普通用户：只需三步

1. App 首页选择 **故障测试与报告**，挑选问题类别（四小窗、折叠屏/平板、游戏/触控、锁屏解锁、电池发热、卡顿闪退、通知栏手势、其他）。
2. 选择 **5 / 15 / 30 分钟**，点击 **开始自动测试**。切换到其他软件或正常复现问题即可。不要求手动标记；标记只是可选功能。
3. 到期后系统会尝试自动结束并保存一份 TXT 报告。回到本页，必要时填写补充说明并点“保存说明”，再点“导出TXT报告”选位置。不会自动发送给任何人。

## 功耗和时效

本功能默认完全关闭，不需要一直打开诊断页面。一次开始 + 一次结束（如果自愿标记则额外按需读取）；**没有持续日志采集、每秒定时器、录屏、截屏、后台服务、Root 读取、持续联网、额外唤醒锁**。

到期使用 Android 系统一次性 **非唤醒型**定时提醒：手机睡眠时不会为了诊断强制唤醒，实际回调可能由系统合并、延后或取消；下一次用户打开测试页会检查是否已过期并补结束。报告区分“计划结束时间”和“实际采集时间”，延迟时不得把后者冒充准时记录。重启/清理应用也可能导致自动回调失效，回来时会补处理；若系统时间基准重置，报告注明计时可信度受影响。

## 能测到什么，不能测到什么

能记录：机型、Android 版本、App版本、测试类别与操作说明、开始和结束时的整机电量/温度、主屏分辨率与方向、锁屏/交互状态、系统是否报告低内存、四小窗数量/是否挂起、既有运行计数变化、是否有明显进程更换线索、用户说明、可选标记时刻。

**不能自动捕捉过程中的每次触摸/黑屏/卡顿，不能自动识别屏幕像素错位，不能获取其他游戏内部的帧率或专有数据，不能代替完整系统崩溃报告，也不能通过整机电量归因本模块独占功耗。** 用户遇到具体画面异常时仍建议另存截图辅助；任何自动持续录屏或高频检测必须以后单独明示并征求用户同意。

## 隐私与安装

报告只存 App 私有区域的最新一份（新测试前会提醒覆盖），用户主动选择导出位置后才写入；不自动上传、不读取私有聊天、通讯录、应用列表或全量日志。手工填写内容由用户分享前自行核对。

本分支只扩充首页测试工具，未合并 v0.9.20 锁屏省电实验，也未更改主小窗交换、游戏触控、各机型布局或虚拟显示标志。**仅内部候选，仍需真实一加 / N5 / Y700 设备验收自动到期与导出行为。**
