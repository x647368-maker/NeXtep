# 台前调度｜跨窗口默认全设备适配规则（用户于 2026-11-12 明确要求）

> **最高执行原则：只要用户没有明确要求排除某些设备/形态，任何新功能、动画与优化都必须默认评估所有项目支持的设备类型。不能因为问题来自某台设备，就把功能只做给这台设备。** 本文件用于主窗口与备用1–6、工作模式/后续窗口交接，不代表一条新特性已经通过真机测试。新功能是否适配、适配范围和限制应在动手前公开说明。

## 适配分类／必查范围

| 设备类型 | 必须考虑的真实状态 | 当前已知代表 |
| --- | --- | --- |
| Android 直屏手机 | 竖屏、横屏（含视频/游戏）、顶部/左右侧栏、手势栏与系统 Insets | 一加 Ace 7 Pro PMS110，ColorOS17／Android17 |
| 折叠屏 | 闭合/展开、横竖屏、近方形内屏、折叠态变化、原生多栏/平行视窗 | OPPO Find N5 |
| Android 平板 | 横竖屏、顶部与左右排列、不同 DPI/旋转、虚拟显示方向、系统状态栏 | Lenovo Y700 TB324ZC、移植 ColorOS16／Android16 |
| 其他支持的 Android 品牌/尺寸 | 真实尺寸/宽高比/密度、Android API 与 WindowManager 能力、系统手势、分屏/自由窗 | 通用配置与可合理覆盖的物理形态；不能声称所有机型都真机验收 |

## 判定原则

1. 使用**实际设备或显示器**的物理逻辑宽高、密度、可用区域、旋转、Insets、折叠状态、图形/Surface 能力；严禁仅靠 `Build.BRAND`、`Build.MODEL`、移植 ROM 的产品名判断设备。Lenovo Y700 刷入 ColorOS 后可报告 OPPO 型号，不代表是真 OPPO 硬件。
2. 优先以形态和已验证的窗口能力做适配；OEM/机型特例仅在客观平台缺陷证据成立时添加，并说明风险、影响、测试状态。
3. 默认不牺牲既有验收成果：四小窗、真实任务和触控、主窗比例、圆角、快捷栏、手势、在线更新和安全校验等；不通过降低清晰度、替换成常驻截图、冻结第三方任务、静默强制重启来制造假流畅。
4. 如果无法确定是否需要特定设备的额外适配，**先询问用户是否专门支持该机型**，确认后再实施其特例；不得擅自排除其他机型或假称全覆盖。
5. 每轮开发前提供**本次范围与例外列表**；交付时分开列出「源码完成」「编译/单测」「模拟器 HWUI」「设备真机验收」，不能把任何一种自动测试说成实机全通过。
6. 主窗口优先级最高；备用窗口只在独立分支开发，不擅自合并 main、发布或签名；不回退其他备用窗口功能。

## 当前需求：统一「主窗 ↔ 小窗」丝滑交互动画（不是 Y700 独占）

**默认目标适用：** 全部已支持的 Android 设备与屏幕形态；包含 Ace 7 Pro、Find N5 折叠/展开、Y700 竖/横屏、其他同类手机/平板。首次安装的设备没有机型白名单；根据窗口几何、运动能力和用户操作类型选择正确动画。若低端设备/ROM 缺少安全 Surface 能力，保留稳定操作路径并记录降级原因，而非按品牌全局关闭功能。

**预期效果：** 点击交换时原小窗真实任务的过渡视觉从原位平滑移动放大至主窗、原主窗同步缩至原卡片位置；保留圆角与比例，应用内容不拉伸/裁切；其他小窗、壁纸、快捷栏稳定；真正的任务与输入映射由原生命周期管理，仅使用有限过渡层，不用静态截图替代常驻真实任务；连续点击、任务未准备好、旋转/折叠中、回滚或超时应恢复可用状态，不能黑屏/闪白。

**技术事实（2026-11-12 当前源码审查）：** `WorkspaceSwapAnimator` 具有双窗口路径插值与 3D quad 代码，但 `NeXtepWindowController` 点击交换传 `freezeGeometry = drag == null`；`StageSwapTimingPolicy` 对静态点击预览只给 1ms，导致点击交换看不到双向移动/缩放。应提供**全形态默认启用、几何安全检查、性能保护及逐场景回归**的策略；不能只把 `freezeGeometry` 对 Y700 关闭，否则会无意剥夺一加/N5动画。所有现有无变形修复、任务交接门槛及性能保护仍须保留。

**开发顺序：** 先设计并验证跨尺寸安全过渡几何和真实 Task Surface 交接，再将适用策略接入所有手机、折叠/展开、平板的点击交换，并通过单元/JVM／模拟器回归，最后三台代表设备做一次统一真机测试；其他机型提供兼容回退并明确未经实测的范围。

**用户验收口径：** 单靠编译/JVM/HWUI不能证明所有 OEM ROM 丝滑。所有机型在没有可靠可用状态时必须安全回退，且需如实标示未实测。
