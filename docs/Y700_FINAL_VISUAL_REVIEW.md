# Y700 横竖屏＋壁纸错缝修复：独立候选，尚待真机验收

反馈：横屏侧栏应用仍竖长条；竖屏有大片空白；静态/动态壁纸显示裂痕或拼接缝。酷友截图属于旧版 0.9.19-dev，不可用于证明本候选成功。

此分支从 v0.9.24-dev 统一版单独创建，不修改 Ace 7 Pro、OPPO Find N5、工作台任务、输入、游戏、交换或省电实验。

## 已处理
- **Y700 竖屏**：不同数量的实际小窗紧凑排列在上方；「+」按钮挪到最后一个小窗后面。空闲的左侧区域不再由复制/裁剪的壁纸截图覆盖，显示同一原生桌面壁纸。主窗口几何不越界，侧栏保留点击透传与原先任务绑定。整体屏幕自然仍会有部分闲置面积，**不能强迫矩形主应用占据侧栏下方的不规则区域**。
- **Y700 横竖屏壁纸**：使用系统自己绘制的壁纸透过透明顶部/侧栏窗口显示（现有 `FLAG_SHOW_WALLPAPER`），不再单独拷贝位图后分别贴两处。这样避免两张贴图相位/裁剪错位，减少截图和GPU特效开销；如果该第三方移植 ROM 在工作台层未显示原生壁纸，需要真机反馈才能进一步加兼容回退。
- **横屏**：已保留备用4“新建小窗采用真实横屏画布、横屏卡片按自身画布比例显示”的改进，旧小窗不会被强制重建，以免刷新短视频或游戏。若 App 自己锁定竖屏则不能保证横屏内容；现有竖屏任务继续采用等比例窄卡片而不是拉伸扭曲。

## 检查与风险
新增 Y700 竖屏左右侧、1～4 小窗、混合横竖内容、完整宽屏壁纸与一加/N5排除测试。既有 v0.9.8 冻结与后续工作台源校验保持有效；改动的完整旧/新文件 Git SHA-1 双向锁定。实验不采用固定截图替代任务、不重建任务、不缩减四小窗数量。不修改签名和线上更新。

**实际验收阻断**：Y700 ColorOS16 真机用静态/动态壁纸和横/竖屏观察无缝衔接；重建小窗/保留小窗对照，主小窗交换、触控、任务不刷新。Ace、N5 需复测 UI 冻结项。模拟器 HWUI 视觉回归曾因 Rollback preview 未在3秒内稳定而失败；不能跳过或认为本分支已修复此回归。
