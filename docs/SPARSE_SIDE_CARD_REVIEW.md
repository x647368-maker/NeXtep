# 1～3 个侧边小窗等比例放大｜v0.9.26 内测

用户最新截图：左侧只有两个小窗，上下留白明显；希望单/双/三窗增大，但要求主窗尺寸完全不动、画面不拉伸变形、菜单和 + 按钮不能乱飞。

具体算法：
- 手机竖屏、左/右侧栏，1～2 窗每侧水平边距由 8dp 收至 4dp，3窗收至 5dp；卡片高度按每个已存在虚拟显示的原始画面宽高比计算，剩余高度按实际窗口数分配（不能挤进菜单/加号区域）。
- 四窗、顶部横排、手机横屏、N5展开近方屏完全执行原有算法。折叠外屏仍可能沿用紧凑手机配置，需要真机确认。
- Y700 竖屏继续按先前上方紧凑排布，少于四张卡时只用上述更紧的侧边安全留白；末尾添加按钮沿用现有经过边界检查的跟随逻辑。静态/动态壁纸规则不变。
- 一加侧边栏「+」和三点菜单的定位源码未修改，底部保留 44dp 按钮加 12dp 底距共 56dp 的防撞区域。Y700「+」仍会紧跟最后一个小窗，始终在边界内，避免与卡片重叠。
- 纯展示窗口大小变化，不修改虚拟显示本身的尺寸、任务、焦点、触控传输映射、主窗口布局、外部应用隐私或后台监听。

验收阻断：必须通过 Android 编译、大小比例/空隙/防碰撞 JUnit 和真实 HWUI 画面回归，再在一加/平板上确认视觉。若视觉或真机失败，保持 Draft 不面向酷友推广。
